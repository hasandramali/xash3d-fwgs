# SvenClient

SvenClient is a fork of [Xash3D FWGS](https://github.com/FWGS/xash3d-fwgs) focused on running a compatible Sven Co-op client on mobile devices. Its purpose is to let mobile players connect to Sven Co-op servers, not to provide a general-purpose Half-Life engine or host servers.

## Platform Focus

- **Android** is the primary development platform today.
- **iOS** is being ported with a native launcher and Steam integration. Device testing is still needed; the project is very new.
- **Windows and Linux** are not the main focus; development prioritizes Android and iOS rather than desktop use.

SvenClient is an independent community project, not an official Sven Co-op client. Compatibility is still evolving, and some features may be incomplete.

Built on the work of the Xash3D FWGS and HLSDK communities.
